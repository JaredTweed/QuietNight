# Verification

The 2026-10-23 audit found that the ordinary application overlay could not satisfy the notification/Quick Settings requirement. Full-screen mode now uses a user-enabled accessibility overlay and paints the dimming filter directly above system UI. The application overlay remains an app-only fallback. The accessibility service requests no event types, screen content retrieval, gesture injection, or key filtering.

Neither overlay adjusts system brightness or adaptive mode. An upgrade-only recovery routine retires outstanding brightness transactions from earlier versions, preserving subsequent manual changes. Modify system settings is requested only if an old transaction remains and restoration access has been lost; fresh installs do not request it.

Debug APK assembly, optimized unsigned release assembly, and debug lint passed (zero lint errors). All 64 automated tests pass, including the trusted overlay test on Android 9 and 13. Regressions cover complete Down-to-mute and Up-to-normal sequences without delays at audible floors 1, 2, and 5; acknowledgement consumption; Bluetooth calibration and gain-before-hardware ordering; independent Screen/Audio activation; scheduling; legacy brightness restoration; trusted filter composition; service disconnect ownership; and the absence of screen-reading capabilities. Synthetic home, schedule, and audio screenshots are rendered by Robolectric.

The updated debug build was installed on the connected Pixel 8 Pro without clearing data. BX27's saved floor-2 calibration was retained, Audio remained enabled, and system brightness/adaptive mode were unchanged. The current media route was the speaker; calibrated headset behavior was covered by automated tests. An attempted device volume sequence was inconclusive: shell adjustments did not change media volume, and key injection remained behind the locked notification shade. No acoustic or physical-key pass is claimed; the final media index and gain matched their initial values. Full-screen device verification requires the user to enable Quiet Night screen dimming in Android Accessibility settings. It has not yet been claimed as device-verified.

Protected screens, always-on displays, HDR, and OEM restrictions remain outside the guarantee of an overlay. The original Bluetooth-fix branch remains untouched; audit fixes are on feat/sleep-companion.

Android window layering is documented in the [WindowManager.LayoutParams reference](https://developer.android.com/reference/android/view/WindowManager.LayoutParams): application overlays sit below critical system windows. Full-screen mode therefore uses a connected AccessibilityService and TYPE_ACCESSIBILITY_OVERLAY.

The 2026-10-24 icon update adds adaptive launcher resources and an Android 13+ monochrome layer. Launcher and Quick Settings share one moon-and-star vector; the tile refreshes its icon whenever it starts listening. Synthetic [launcher and tile previews](icons.png) cover normal, light-themed, and dark-themed rendering. Tile regression coverage checks both Audio states and verifies that two taps change only Screen, preserving the other settings. All 66 tests, debug assembly, and debug lint pass. The updated debug build was installed without clearing app data.

The minimal UI revision removes the introductory hero, repeated instructions, and footer. It uses compact Screen, Screen schedule, and active Sound cards, a segmented schedule selector, wallpaper-based Material color roles where supported, and a fixed bar with independent Screen/Audio controls. Help, privacy, and licenses remain in the overflow menu. No audio, dimming, permission, calibration, or scheduling engine behavior changed.

The full 68-test suite, debug/release assembly, and debug lint passed. The six home-screen checks were re-run after stabilizing bitmap captures with software layers and checking both toggles' visibility and opacity. Layout checks include a 360 dp phone, custom scheduling, independent toggles, and access to Help/privacy/licenses. The final debug APK was installed on the connected Pixel without clearing data.
